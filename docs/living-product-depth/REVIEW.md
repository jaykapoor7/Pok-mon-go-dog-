# Design, motion and boundary review

## Screenshot critique

First pass: the existing brand remains recognizable without its logo: blue reading field, botanical palampore, Pinky's labelled sample record, ink request workbench, coral ecosystem and museum dog painting. The missing live faces and real map were the substantive gaps, not a reason to replace the entire direction.

Second pass: actual screenshots revealed the municipal page inside the app shell, crowded mobile trail controls, long art-credit wrapping beside the phone task, and map tools colliding with the city title. Fixed the marketing route classification, used a two-column phone trail, compact linked credits, and preview-specific map controls. The report form now becomes a small receipt after Send; repeated act descriptions and caution paragraphs are removed.

The full-page local captures show honest unavailable states because the local build has no Supabase credentials. Gallery captures are a separately identified component harness using ten genuine, previously photo-reviewed public records fetched through the existing public search/area API. Map captures run the actual local public map component with read-only production API responses, fetched in the public browser context. These are not screenshots of the protected Vercel deployment and not a claim that the local build has production credentials.

No image generation, invented profile name, generated animal photo, testimonial, municipal customer or outcome was added. Historical and folk artworks retain their existing credit/licence pages. Photo provenance and removal access remain on the actual public profiles.

## Motion review

| Before | After | Why |
| --- | --- | --- |
| No real profile rows | Two slow linear rows; pause control, hover and profile-focus pause, offscreen pause, reduced-motion/static strips | Explicitly requested documentary browsing; never a forced reading sequence. |
| Send left a full form alongside the workspace | Compact receipt and 220ms transform/opacity intake arrival | Shows the same observation entering the queue without adding a cinematic stage. |
| Narrow map layer strip and expanding search | Two-column preview layer controls on phones, instant search expansion | Every layer remains visible and touch reachable. |
| Repeated staged explanations | Immediate view/role controls with actual state metadata | A viewed history tab does not imply completed review, treatment or linkage. |

Review decision: approve this bounded motion implementation. No scroll pinning, new animation dependency, moving reading text, or layout-property animation was added. The only ambient animation is explicitly requested, optional gallery browsing. Existing operational map motion is reused; the landing does not modify its engine or business behavior.

## Boundaries

- The example remains memory-only. Send, acceptance, assignment, undo, edit and replay have no transport, persistence or real identities.
- Public animal links use the returned UUID. Gallery reads are restricted to the pre-existing manual photo-review list and non-sensitive, non-injured public records; no broad fallback to unreviewed photos.
- Map preview uses public scope and the existing city variant, with no report/case actions. Its URL and Escape behavior live inside its own document. Closing unmounts it. Geolocation is unavailable in this iframe, so its location control is hidden.
- Municipal step controls explain the commercial service; they create no verification decision, payment or field assignment. No payment processor, disbursement ledger, WhatsApp transport or automated verification engine is implemented by this marketing change.
- ₹999/month per NGO is supplied by the user. No invented usage price, Meta surcharge, signed contract, tax inclusion or deployment claim is added.
- Partner proof reuses the existing operational/pilot partner source, including its documented founding relationship. Directory listings are accessed through the directory; they are not presented as new partnerships.
- No schema, migration, RLS, authentication or private workspace changes.
