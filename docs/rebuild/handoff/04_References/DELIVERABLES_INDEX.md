## What to study and copy as **interaction patterns**
**Attio**: home composition, list/record density, attribute left column, tabs inside record drawer, inline editing, real activity timeline, action-needed inbox.
**Linear**: Insights layout, analytics, command/search, views/filters, smooth persistent work state.
**Raycast**: Kaju compact assistant + expanded workspace, commands, quick responses, context, source-rich results, keyboard-first feel.
**Slack**: native organization/programme channels, conversations, threads, DMs, channel tabs and human communication culture.
**Inngest**: mission step progression, execution timeline, replay/cancel/retry evidence, status and exception handling.
**Motion/Animate UI**: fast springs, animated primitives, tasteful success states, shared-element expansion, reduced-motion safe.
