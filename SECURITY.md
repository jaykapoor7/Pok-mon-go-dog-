# Security policy

StrayPaw handles animal welfare programme records, partner workspace access and location-based evidence. We take access control, data integrity and the protection of reporters and field teams seriously.

## Reporting a vulnerability

Do **not** disclose a suspected vulnerability, credential, private record or exploit path in a public GitHub issue.

If GitHub's private vulnerability reporting is enabled for this repository, use that channel. Otherwise, contact the maintainers privately via [straypaw.org/contact](https://straypaw.org/contact), clearly marking the message as a security report. Include a minimal reproduction and the affected component; do not attach private partner or reporter data unless an authorised secure channel has been arranged.

We will review reports and coordinate remediation and disclosure appropriate to the severity and affected users. This document does not promise a fixed response or resolution time.

## Scope

Product deployment, authentication, row-level security, private evidence access and API endpoints are in scope. Do not test against real partner accounts or production records without prior authorisation.
